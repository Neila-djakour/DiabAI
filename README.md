# DiabAI 🩺

DiabAI is a diabetes-focused AI assistant built as part of my ThirdUni AI learning journey.

## About the project

DiabAI explores how AI can support medical education and healthcare through a simple AI agent.

The project was built while learning LangChain and Gemini from the ground up.

## What I learned

- Working with Gemini models
- Building AI agents with LangChain
- Creating tools for an AI agent
- Short-term agent memory
- System prompts and few-shot prompting
- Multimodal AI concepts

## Current features

- Diabetes education assistant
- BMI calculation tool
- Short-term conversational memory
- Basic multimodal AI experimentation

## Technology

- Python
- LangChain
- Google Gemini
- VS Code

## Disclaimer

DiabAI is an educational project and is not intended to diagnose medical conditions or replace professional medical advice.
